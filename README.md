# Image Pansharpening

> **Note:** this is a guided lab exercise completed as coursework at Télécom Paris / Institut Polytechnique de Paris — the notebook scaffolding (introduction, some helper code) was provided by the course instructors, and the derivations, analysis, and completed implementation are the author's own work.

Guided lab exercise (Télécom Paris) on the pansharpening problem in remote sensing: fusing a high-spatial-resolution panchromatic image with a lower-resolution multispectral (RGB) image of the same scene to produce a high-resolution color image, implementing and comparing several classical pansharpening methods.

**Author(s):** Maxime Appert

**Stack:** Python, NumPy, image processing, remote sensing
